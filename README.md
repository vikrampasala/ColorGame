# RGB Color Guesser Game

A fun, interactive web game where players test their knowledge of RGB (Red, Green, Blue) color codes. 

## 🎮 How to Play
* The game asks you **5 questions** about a specific RGB value.
* You have to **pick the correct color** that matches the code.
* At the end, you get a **final score out of 5** based on how well you did (Well, Average, or Bad).
* There are **3 difficulty levels**: Easy, Medium, and Hard.

## 🛠️ Built With
* **HTML5** - For the structure of the game pages.
* **CSS3** - For styling, colors, and layouts.

## 🚀 How to Run the Game Locally
Since this is built with pure HTML and CSS, you do not need to install anything!

1. **Download the code**: Click the green **Code** button at the top of this GitHub page and select **Download ZIP** (or clone it if you know how).
2. **Extract the files**: Unzip the folder on your computer.
3. **Play**: Double-click the `ColorGame.html` file to open the game instantly in your web browser (Chrome, Safari, Edge, etc.).
